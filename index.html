Privacy-First School AI Suite

In development · school pilot

Two agents built for a K-12 school, both engineered around a hard constraint: no student or staff record may leave the school's own servers. Decision Radar reads staff email and recommends which stakeholders need to be informed of a given change. Cloze generates tiered, per-student practice worksheets from each student's tracked skill level — designed so no student can tell their own level from the sheet. Both run on a locally-hosted language model (Ollama), with no cloud dependency.
